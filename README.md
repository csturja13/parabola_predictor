# parabola_predictor
Determine the coefficients of a parabola given only the x and y axes of it, using backpropagation (NN).  
It supports parabola equations only of type: y = w(x^2) + b  
You can provide your own x and y coordinates of your preferred parabola in the x_vals and y_vals lists.  
Here "a" is the learning rate "alpha"...
